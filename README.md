# Platform Fighter

This is a work-in-progress Platform Fighter Unity game.
The name for this project will be updated eventually once the game has more of an identity.

Current logs of daily progress, notes, and the backlog can be located in the PlatformFighterDevBlog.txt file

## Large end goals for this project:
- Rollback Netcode (either using a library or implementing my own)
- Unique models/animations for each fighter
- Provide an export of the game so users dont need to use the Unity editor to play
- Gamecube Controller support

## Running this project locally
- This project currently uses Unity Editor Version 6000.4.1f1
- Run ```git clone https://github.com/aidan-smagh/PlatformFighter.git```
- In UnityHub hit Add > Add project from disk > Select the PlatformFighter folder
